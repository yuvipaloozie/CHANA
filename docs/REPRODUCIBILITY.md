# Reproducibility notes

This page collects the technical details that are not needed in the main
README. Start with the root [`README.md`](../README.md) for installation,
inference, evaluation, and the repository map.

## Scope and intended use

CHANA segments expert-defined osteoclast regions in TRAP-stained bright-field
culture images. It produces semantic probabilities, binary masks, watershed
objects, counts, and morphometric measurements. It is research software for
retrospective analysis in settings similar to the study data. It has not been
validated for clinical decisions, independent verification of the three-nuclei
criterion, prospective drug screening, or untested stains, microscopes, species,
cell lines, or tissues.

The fixed test set contains 281 images. The available records do not establish
scan-, well-, or biological-replicate independence, so the set should be
described only as a fixed image-level holdout. Dense and overlapping regions can
merge, fragment, or produce watershed artifacts; external-site generalization
and probability calibration have not been established.

## Data and splits

| Domain or split | Images | Label source |
|---|---:|---|
| Diffusion-derived | 3,000 | Generated masks |
| Copy-paste | 1,500 | Transformed objects and masks |
| Pseudo-labelled real | 2,058 | Fixed TransUNet teacher |
| Expert-real training | 1,629 | Expert semantic masks |
| Expert-real validation | 281 | Expert semantic masks |
| Expert-real test | 281 | Expert semantic masks |

The expert-real total is 2,191 image-mask pairs. Curriculum exposures are not
additional independently collected biological samples. The 1,910 images shown
for the final curriculum phase in the supplementary table comprise 1,629
training and 281 validation images; optimization uses the training partition.

The archival dataset should include a CSV with stable image ID, relative image
and mask paths, split, and source-scan ID. Group independence should not be
claimed unless the original split records confirm that source scans do not
cross development and test partitions.

The cleared example under `sample_data/public_example/` is suitable for fresh
inference. Its supplied reference probability map is internally consistent but
is not tied to a registered checkpoint. The complete test data and other large
artifacts may be hosted in the associated data archive rather than GitHub.

## Model and output definitions

The six evaluation models compare U-Net, U-Net++, and TransUNet trained either
on expert-real data alone or with the sequential curriculum. Canonical model
IDs, checkpoint names, historical aliases, byte sizes, and SHA-256 hashes are
recorded in [`manifests/model_registry.csv`](../manifests/model_registry.csv).
The historical `Domain` and `no_Domain` checkpoint suffixes were reversed; use
the canonical IDs and hashes, not the old filenames.

`transunet_pseudolabel_teacher.weights.h5` is a data-generation dependency, not
a seventh evaluation model. TransUNet must be built with the ImageNet-initialized
EfficientNetB0 encoder before its H5 checkpoint is loaded. Repository inference
and validation commands do this automatically.

Probabilities are thresholded at `> 0.5`. Foreground holes are filled, then a
distance-transform watershed uses 20-pixel peak spacing. Objects with areas from
50 through 10,000 pixels are retained. These are algorithmic objects rather
than manually assigned instance identities. Evaluation includes IoU, Dice,
pixel average precision, finite HD95, centroid-matched object metrics with a
25-pixel gate, and count error.

## Training

Shared segmentation settings are 512 × 512 RGB inputs, batch size 16, AdamW
with weight decay 1 × 10⁻⁴, and cosine learning-rate decay. Trusted labels use
focal Tversky loss (`alpha` FN = 0.3, `beta` FP = 0.7, `gamma` = 1.5). The
pseudo-labelled phase uses binary cross-entropy with label smoothing 0.1 where
specified by the original export. Augmentation includes flips, rotations up to
20 degrees, brightness/contrast changes, and coarse dropout.

Baseline maximum epochs are 400 for U-Net, 500 for U-Net++, and 400 for
TransUNet; initial learning rates are 1 × 10⁻⁴, 1 × 10⁻⁴, and 1 × 10⁻⁵,
respectively. Curriculum checkpoints transfer weights in this order:

| Phase | Images | Maximum epochs | Initial learning rate |
|---|---:|---:|---:|
| Diffusion-derived | 3,000 | 40 | 1 × 10⁻⁴ |
| Copy-paste | 1,500 | 80 | 5 × 10⁻⁵ |
| Pseudo-labelled real | 2,058 | 50 | 2 × 10⁻⁵ |
| Expert-labelled real | 1,629 | 200 | 1 × 10⁻⁵ |

Pseudo-labels were generated by the fixed teacher whose historical filename was
`transunet_stage3_real_finetune.weights.h5`; they were not generated separately
from each architecture's preceding curriculum checkpoint.

The training and data-generation programs under
`notebooks/legacy/python_exports/` are original Colab exports. Set their Drive
paths and use the matching environment before execution. They may retain Colab
magics and installation cells; the reusable local inference implementation is
under `src/chana/`. Selected epochs should be taken from the original logs when
those logs are archived rather than inferred from checkpoint filenames.

## Evaluation boundary and source data

Validation images may be used for checkpoint selection. The 281 test images
must not be used for model selection, threshold tuning, or figure-driven
iteration. Final analyses should use the frozen split record and model registry.

Readable manuscript tables and their CSV files are under [`paper/`](../paper/).
The full pixel precision-recall coordinates are in
`paper/source_data/Figure_4A_pixel_PR_curves_full.csv.gz`. Additional plot data
should be deposited as CSV or NPZ exports when recovered; numerical values
should not be reconstructed by digitizing figure images. The legacy analysis
exports under `paper/analysis/legacy/` retain their original private paths.

For the compact external-method comparison, see
[`benchmarks/external_methods/README.md`](../benchmarks/external_methods/README.md).
