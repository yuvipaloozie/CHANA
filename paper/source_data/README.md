# Plot source data

`Figure_4A_pixel_PR_curves_full.csv.gz` contains the full pixel
precision-recall coordinates for all six models. The final table CSVs are in
[`../tables/`](../tables/), and the readable results are in
[`../README.md`](../README.md).

The image-level/object-level results, UMAP and feature-distance values, and
robustness-analysis data behind the remaining final plots have not yet been
deposited. Add the original CSV/NPZ exports when available; do not infer numeric
values by digitizing publication graphics.
